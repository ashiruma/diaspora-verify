# Workspace Rules: DiasporaVerify

## Rule 1: Zero Emojis
- ZERO emojis on any work, UI, code, markdown, comments, or documentation across all projects.
- Never use unicode emoji characters (e.g., flags, crowns, status faces, checkmark emojis, etc.).
- Always use clean SVG icons (such as Lucide React icons) or clean typographic text/badges instead.

## Rule 2: Security & Strict Data Leak Prevention
- Security is paramount for high-value clients and operations.
- Field agents must NEVER receive or view personal client contact information (client phone numbers, personal emails, full personal names).
- Clients must NEVER receive or view agent personal contact information (agent phone numbers, personal emails).
- All communications, negotiations, and payments must flow strictly through the platform coordinator.
